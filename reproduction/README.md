# Reproduction

This directory is reserved for code that independently reproduces the published Bastani et al. results before any novel secondary analysis.

Initial checkpoint reproduced during project development:

- Primary non-Honors specification
- Complete-case adjustment for prior GPA
- Teacher/session/grader/year fixed effects
- Standard errors clustered by class
- GPT Base: higher assisted Part 2 performance and lower subsequent AI-free Part 3 performance
- GPT Tutor: substantially higher assisted Part 2 performance with no detectable Part 3 penalty

Exact scripts should be committed here once run on the user's local machine with the upstream source snapshot.
