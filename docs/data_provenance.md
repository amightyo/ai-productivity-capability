# Data provenance

## Primary source

Bastani et al. public replication repository: `obastani/GenAICanHarmLearning`.

Source URL: https://github.com/obastani/GenAICanHarmLearning

The present project does not claim ownership of the source data and does not redistribute raw source files. Analyses should cite the original study and source repository.

## Local source snapshot used during initial audit

The source repository was supplied as `GenAICanHarmLearning-main.zip` on 2026-09-30 for reproducibility and secondary analysis.

Before public release, record the exact upstream Git commit hash corresponding to the downloaded snapshot if available.

## Derived data

`data/derived/bastani_matched_panel_pre_nlp.csv` is a derived matched-task panel constructed from the source data. Its redistribution status should be checked against the source-data license before committing it publicly. Until that check is complete, treat it as local-only.
